## Возможности

### Получение схемы базы

| Способ | Что читается |
|---|---|
| Подключение к **SQLite** (файл, режим «только чтение») | таблицы, представления, колонки, PK, внешние ключи |
| Подключение к **PostgreSQL** | таблицы, представления, колонки, PK, внешние ключи |
| Подключение к **MS SQL Server** (логин/пароль или Windows-аутентификация) | таблицы, представления, колонки, PK, внешние ключи |
| Загрузка из **файла** — DDL-скрипт (`CREATE TABLE …`) или JSON | то, что объявлено в файле |

Схему можно выгрузить в JSON и использовать повторно (например, для работы без доступа к базе).

### Конструктор запросов — как в 1С

- **Таблицы и поля** — таблицы запроса с псевдонимами (`t1`, `t2`, …), выбор полей по одному,
  кнопка «Выбрать все поля», псевдонимы колонок, агрегатные функции
  (`COUNT`, `COUNT(DISTINCT)`, `SUM`, `AVG`, `MIN`, `MAX`), `DISTINCT`, ограничение строк;
- **Связи** — `INNER` / `LEFT` / `RIGHT` / `FULL` / `CROSS JOIN`; при добавлении таблицы связь по
  внешнему ключу создаётся автоматически;
- **Группировка** — `GROUP BY` по выбранным полям и условия итогов (`HAVING`) по агрегатам;
- **Условия** — отборы «ВидСравнения» как в 1С: *Равно, Не равно, Больше/Меньше, Содержит,
  Начинается с, Оканчивается на, В списке, Между, Пусто* и т. д., объединение по **И / ИЛИ**;
- **Порядок** — сортировка по возрастанию / убыванию;
- **Скрипт** — подготовительный SQL и пакетные запросы (см. ниже);
- **SQL и результат** — живой предпросмотр текста запроса, копирование в буфер,
  выполнение (**F5**) с выводом результата в таблицу.

### Прочее

- Мгновенный предпросмотр SQL при любом изменении;
- Корректный диалект для каждой СУБД: `LIMIT` для SQLite/PostgreSQL, `TOP (n)` для MS SQL;
- Экранирование идентификаторов (`"…"`) и значений (по типу колонки — числа без кавычек);
- Сохранение/открытие запросов в файл `.sqj` (JSON, включая скрипт);
- Автозащита при выполнении: если в запросе нет ограничения строк, выборка ограничивается автоматически;
- Тёмная компактная тема (Fluent `DensityStyle=Compact`), единый стиль всех контролов.

## Быстрый старт

Требуется [SDK .NET 10](https://dotnet.microsoft.com/download/dotnet/10.0). Зависимости (Avalonia 12,
Npgsql, Microsoft.Data.Sqlite, Microsoft.Data.SqlClient, CommunityToolkit.Mvvm) подтягиваются автоматически.

```bash
git clone <url-репозитория>
cd SQLConstruct
dotnet run --project src/SQLConstruct
```

Сборка решения и тесты:

```bash
dotnet build SQLConstruct.slnx
dotnet run --project tests/SQLConstruct.Tests
```

## Как пользоваться

1. **Подключитесь к базе**: меню *База данных → Подключиться к SQLite / PostgreSQL / MS SQL…*
   или загрузите схему из DDL/JSON-файла. Слева появится дерево «Схема базы» с поиском.
2. **Добавьте таблицы**: двойной клик по таблице или отдельному полю в дереве.
   Связи по внешним ключам создаются сами, остальное — на вкладке «Связи».
3. **Соберите запрос**: поля выборки (псевдонимы, агрегаты) → отборы → группировка → порядок.
   SQL-текст на соответствующей вкладке обновляется на лету.
4. **Выполните** (кнопка или F5) и смотрите результат; **копируйте** SQL в буфер одной кнопкой.
5. При необходимости сохраните запрос (*Файл → Сохранить запрос…*) в `.sqj` и откройте позже.

## Пакетные запросы и временные таблицы

На вкладке **«Скрипт»** пишется подготовительный SQL, который выполняется перед основным запросом
**одним пакетом**; результатом считается последний `SELECT`:

```sql
DROP TABLE IF EXISTS #report;
CREATE TABLE #report (id INT PRIMARY KEY, name NVARCHAR(100), amount NUMERIC(10,2));
INSERT INTO #report (id, name, amount)
SELECT u.id, u.name, o.amount
FROM users u JOIN orders o ON o.user_id = u.id;

-- основной запрос конструктора выполняется следом и может использовать #report
```

- Таблицы из `CREATE TABLE` / `CREATE TEMP TABLE` попадают в дерево схемы
  (кнопка «Обновить таблицы из скрипта» — и автоматически перед каждым выполнением)
  и помечаются как «временная таблица»;
- Пакет выполняется заново при каждом запуске — пишите скрипт идемпотентно (`DROP TABLE IF EXISTS …`);
- Скрипт входит в сохраняемый файл запроса `.sqj` и в копируемый SQL.

## Структура проекта

```
SQLConstruct/
├── src/SQLConstruct/
│   ├── Models/                     # схема БД и сериализуемая модель запроса
│   ├── Services/
│   │   ├── QuerySqlBuilder.cs      # генерация SQL (диалекты LIMIT / TOP)

│   │   ├── DbExecutor.cs           # выполнение запросов и пакетов
```

## Формат JSON-схемы

Схему можно подготовить вручную (или выгрузить из подключённой базы) и загрузить через
*База данных → Загрузить схему из файла…*:

```json
{
  "Name": "mydb",
  "Provider": "Sqlite",
  "Tables": [
    {
      "Schema": "",
      "Name": "users",
      "IsView": false,
      "Columns": [
        { "Name": "id", "DbType": "INTEGER", "IsNullable": false, "IsPrimaryKey": true },
        { "Name": "name", "DbType": "TEXT", "IsNullable": false, "IsPrimaryKey": false }
      ],
      "ForeignKeys": [
        { "SourceTable": "users", "SourceColumn": "city_id", "TargetTable": "cities", "TargetColumn": "id" }
      ]
    }
  ]
}
```

## Тестирование

`tests/SQLConstruct.Tests` — консольный набор из 58 проверок без внешних зависимостей:

- генератор SQL (выборка, JOIN, WHERE всех видов сравнения, GROUP BY/HAVING, ORDER BY, LIMIT/TOP-диалекты);
- DDL-парсер (типы с длиной, NOT NULL, PK, REFERENCES, `#временные` таблицы);
- ридер SQLite на живой временной базе (таблицы, представление, FK);
- пакетное выполнение с временной таблицей и защитная обёртка выборки;
- логика конструктора («Выбрать все поля», события обновления схемы).

## Известные ограничения

- Условие соединения — по одному равенству полей на строку связи (несколько строк с одной
  присоединяемой таблицей объединяются через `AND`);
- Составные внешние ключи упрощаются до первой колонки;
- `UNION` / объединения нескольких запросов не поддерживаются — пакетная работа через вкладку «Скрипт»;
- Временные таблицы попадают в схему разбором `CREATE TABLE`; таблицы из
  `SELECT INTO` / `CREATE TABLE AS SELECT` объявите явно;
- Для схемы, загруженной из файла, доступно только конструирование и текст SQL
  (выполнение — при живом подключении).
